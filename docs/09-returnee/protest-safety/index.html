    参加海外游行活动的安全注意 #

    一、筹备期的安全注意 #

    1. 通讯与协调 #

    • 所有内部协调在 Signal 专用群组进行，绝不使用微信等中国平台
    • 个人社交媒体账号可用于公开宣传和表达支持，但绝不用于内部协调
    • 内部协调信息（成员信息、决策讨论、应急预案）只走 Signal，并设置定期自动删除
    • 活动文件存储在组织专用账号的 Proton Drive 或 CryptPad，不存储在任何成员的个人账号

    2. 报名与动员 #

    • 内部动员通过 Signal 进行
    • 若需要对外公开报名，采用 CryptPad 表单，链接通过口耳相传或 Signal 传递，不公开发布
    • 报名表不收集真实姓名

    3. 法律合规 #

    了解所在国家或地区与游行相关的法律规定，确保不触犯当地法律。

    4. 应急预案 #

    • 提前确认当地法律援助热线，所有参与者知道这个号码
    • 指定一名在现场的协调员，处理突发状况，详见后文
    • 指定一名不参与游行的后方联络人，负责紧急情况下的协调
    • 所有参与者提前知道：被警察问询时，有权保持沉默，有权要求律师

    二、活动当天的安全注意 #

    1. 个人防护：按情境判断 #

    参加活动前，先做两个判断：

    判断一：这次活动的组织者是谁？ 

    • 本地人或本地组织主导 → 你是参与者，曝光程度天然较低
    • 中国背景的活动者组织 → 你是组织者或核心参与者，曝光程度较高

    判断二：活动话题是否直接针对中国政府？ 

    • 一般议题 → 中国当局识别你的动机较低。但如果你本人或所在社群影响力较大，则风险也会上升
    • 批评中国政府、前往中国使馆、涉及新疆西藏香港台湾等议题 → 中国当局识别你的动机较高

    对应防护级别

    • 低防护（本地人组织 + 话题不针对中国政府）

      • 正常参与，无需特别措施
      • 避免在媒体镜头前主动发言

    • 中防护（本地人组织 + 话题涉及中国政府，或中国行动者组织 + 一般性话题）

      • 建议佩戴口罩
      • 避免在横幅或标语上署名
      • 避免接受媒体采访，或采访时要求不拍摄面部

    • 高防护（中国背景的人组织 + 话题直接针对中国政府，尤其是前往中国使馆）

      • 口罩覆盖鼻子以下
      • 帽子或连帽衫
      • 避免穿着过于独特的服装
      • 不在现场用真实姓名呼叫他人
      • 横幅和标语不署真实姓名

    2. 特殊情境一：以个人身份参加当地游行 #

    行动者以个人身份参加本地人组织的游行，但在现场使用中文打出标语，标语内容包括直接支持中国某些/某些弱势人群，或直接批评中国政府/中国共产党/高层领导人，或喊出相关口号。

    行动前的判断：

    在决定打标语或喊口号之前，先问自己：

    如果这个画面明天出现在中国媒体上，或出现在中国当局的档案里，我能接受吗？

    如果答案是否定的，口罩就是必须的。

    如果选择打标语、喊口号：

    • 佩戴口罩和帽子，在游行现场这是完全正常的，不会引起注意
    • 标语优先使用英文或当地语言，而不是中文——中文标语会明确标记你的身份来源，更容易被中国媒体或便衣人员单独拍摄
    • 标语上不出现真实姓名或任何可识别信息
    • 跟随人群喊口号，而不是单独领喊——单独领喊会吸引镜头单独捕捉
    • 与周围人自然融入，不刻意聚集成可识别的中国人小组
    • 不在现场实时直播（社交媒体直播或者视频网站直播）或上传内容
    • 不在任何中国平台分享自己参与的内容

    关于媒体采访

    • 拒绝采访是最安全的选择 
    • 若选择接受：使用化名，明确要求记者不发布可识别的面部画面，不透露就读学校、所在城市等可定位信息

    如果选择不打标语、不喊口号 

    • 低防护情境下可正常参与，无需口罩
    • 即使自己不打标语，但如果站在涉及中国的标语旁边被拍到，画面仍可能产生关联——与其他中国参与者自然分散在人群中，而不是聚集在一起
    • 事后可在个人社交媒体表达支持，但不发布可识别自己身份的现场照片

    3. 特殊情境二：组成中国相关的方队参加当地游行 #

    多名中国背景的行动者在游行中以集体形式出现，打出涉及中国的标语或喊出相关口号，标语内容包括直接支持中国某些/某些弱势人群，或直接批评中国政府/中国共产党/高层领导人，或喊出相关口号。

    行动前必须明确

    中国相关的方队本身就是一个公开声明。方队的存在会吸引媒体和旁观者的专门关注，参与者比散落在人群中的个人更容易被单独识别，中国当局也更有动机追踪一个有组织的集体行动。

    ⚠️ 所有参与者必须在组队前——而不是游行当天——明确理解并接受这个风险级别。

    如果选择打标语、喊口号

    • 全员佩戴口罩和帽子，这是底线，无例外
    • 标语统一使用英文或当地语言，避免中文
    • 标语和口号内容提前在 Signal 内部确认，不在现场临时决定
    • 口号跟随集体喊，不设个人领喊——若必须有人领喊，必须是防护最完整的人
    • 方队不使用任何包含真实姓名、学校、组织名称的标识
    • 不接受任何媒体采访——方队作为集体目标，媒体关注度远高于个人参与者
    • 不在任何中国平台宣传或记录方队的存在
    • 指定一名在现场的协调员，处理突发状况，详下
    • 指定一名不参与游行的后方联络人，全程保持 Signal 联系
    • 游行结束后当天，所有成员删除现场照片和视频，包括云端备份

    关于标语内容的提醒

    无论是提前制作好的标语，还是临时带到现场的标语，请在举起之前考虑以下几点。

    直接且激烈批评中国政府或中国领导人的标语，可能给举牌者带来现实风险。我们尊重每个人表达的权利，也希望每个人在做出决定和行动之前，认真权衡风险与表达之间的平衡：

    • 如果你决定公开表达，请采取相应的身份保护措施——口罩、帽子、避免被单独拍摄。
    • 如果你不愿意采取保护措施，建议在措辞上有所克制，避免使用最直接的批评性表达。
    • 如果你既不愿意保护身份，又希望公开表达激烈批评，请务必清醒地意识到这样做的潜在后果，并且是在充分知情的前提下做出这个选择。

    还有一点同样重要，却常常被忽视：

    如果现场有人举起激烈批评的标语，附近的人即使自己什么都没有举，也可能出现在同一张照片或同一段视频里。一个人的选择，可能在其不知情的情况下，影响到身边的每一个人。

    这不是要求任何人放弃表达。这是提醒每个人：在公开场合，我们的行为从来不只关乎自己。

    如果选择不打标语、不喊口号

    • 以中国行动的集体身份出现在游行中，本身就是一种表达
    • 口罩由个人根据风险评估自行决定，不强制统一
    • 方队集体照片发布前，必须逐一确认每位成员同意，并处理不同意公开的成员的面部——方队画面里的人比个人参与更多，知情同意的确认更重要

    现场协调员

    协调员不是管理者，不发号施令。其职责是在现场保持观察，在需要的时候轻声提醒、协助处理——让每个人都能专注于活动本身，而不必分心去注意周围的情况。

    协调员负责什么

    • 留意异常拍摄行为：游行现场有人拍照是正常的，但如果有人持续、专门地对准方队成员的面部拍摄，协调员需要注意到这一点。可以走近对方，礼貌地询问拍摄目的，或者提示方队成员用手或标语遮挡面部。不需要对抗，也不需要没收任何人的设备——公共场所无法阻止他人拍摄，能做的是让方队成员不那么容易被清晰识别。
    • 提醒防护不完整的成员：如果方队中有人打出了激进标语，但没有佩戴口罩，协调员需要在第一时间轻声提醒。这不是批评，而是帮成员完成自己也认同的保护。提醒的方式应该简短、不引起注意：走近，低声说一句，递上备用口罩。协调员应该随身携带几个备用口罩，以备成员忘带或口罩损坏。
    • 处理临时状况：游行中可能出现各种预料之外的情况：有人身体不适、有人与陌生人发生口角、有人迷失在人群中。协调员是第一个注意到这些情况并介入的人，同时保持与后方联络人的 Signal 联系，必要时上报。

    协调员不负责什么

    协调员不是安全审查员，不评判成员的政治立场，也不决定谁可以打什么标语。其工作边界是操作层面的安全提醒，而不是内容层面的管控。

    4. 面对外部拍摄 #

    • 公共空间无法阻止他人拍摄，唯一的应对是让自己不可识别
    • 若发现有人专门针对性拍摄参与者面部，可用手或标语遮挡，这在法律上是允许的

    三、活动结束后的安全措施 #

    1. 照片与内容处理 #

    • 所有参与者检查手机，当天之内必须删除现场照片，清空相册回收站
    • 检查云端自动备份：iCloud、Google Drive，以及华为云、小米云等中国品牌云服务

    2. 内容发布 #

    • 若需发布活动照片：
      • 所有面部必须模糊，无例外
      • 清除图片元数据
      • 个人账号可发布，但发布前确认照片中其他人已同意且面部已处理
      • 不在中国平台发布

    3. 媒体应对 #

    • 若有媒体采访：参与者有权拒绝，有权要求不拍摄面部
    • 若接受采访：使用化名，明确要求媒体不展示可识别特征

    4. 返回中国前的检查 #

    • 删除手机中所有活动相关照片，清空回收站
    • 检查并清理所有云端备份
    • 清理 Signal 中的活动相关聊天记录，或退出相关群组
    • 高防护级别的活动参与者：考虑携带干净备用手机入境，行动手机留在境外
    • 撤销该成员对组织网盘的访问权限，确保其在中国境内无法访问任何小组或活动数据
