      九、海外人士回国，遭遇电子产品检查或警察盘问

      海外人士回国，遭遇电子产品检查或警察盘问 #

      如果你常居海外，以公开或匿名的身份参与一些敏感的公民活动。那么，在你返回中国的时候就要当心。

      一方面，你可能会遭遇电子产品检查，这些检查可能是直接针对你个人的，也可能只是随机检查的一部分。另一方面，如果你公开参与过海外的公民活动，那么你可能会被中国警察盘问。

      被讯问有时是概率性事件，但哪怕只有百分之一的风险，我们也要关注和预防。

      想要持续关注中国人权，必须要有一线安全注意的警惕线在心里。安全注意并不是为了吓唬自己，而是为了我们有更多的可持续的活动空间。
