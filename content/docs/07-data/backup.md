# 定期备份你的重要数据

你应该养成良好的数据备份习惯，尤其是将那些重要的文件定期备份，以免电脑、手机丢失和损坏之后导致重要数据丢失。

备份的一个原则是，不要让这个文件只有一份，而应该同时在多个（至少两个）设备上面保存，以免其中之一遗失或损坏之后永远失去这些文件。

前面已经推荐介绍强大的文件和系统加密软件 Veracrypt。 你要备份重要数据的时候，也应该使用 Veracrypt 加密所有的文件。可以按照类型，分成若干个不同的加密文件。比如重要的个人证件合同是一类，生成一个加密文件；个人私密照片是一类，生成另一个加密文件；敏感的线上活动是一类，单独生成一个加密文件……诸如此类。

Veracrypt 的加密文件可以复制、移动。也就是说，在电脑硬盘上面加密的文件，可以复制到移动硬盘保存。以后需要使用的时候，也可以使用 Veracrypt 从移动硬盘打开。
