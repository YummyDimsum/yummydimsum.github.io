# 其它软件

## 一、音频及视频播放器

无论在哪个系统上面，都推荐使用 VLC player.

https://www.videolan.org/vlc/

在介绍隐私与安全的时候，冷不丁开始介绍多媒体播放器，是不是多此一举呢？并非如此。正如我们很多次说过的那样，安全与隐私与许多因素相关，其中非常重要的一点就是：<u>**不要使用国产软件**</u>。

我们设想，你可能也是个喜欢听音乐、看电影的人，总会用到多媒体播放器。既然要用，就用一个干净、安全的播放器吧，而不是随便下载一个国产软件。

## 二、还有很多

还有一些软件，我们将它放在下一部分《[上网安全](/docs/05-internet/)》《[通讯安全](/docs/06-communication/)》《[数据安全](/docs/07-data/)》的相关小节来介绍。

此外，不同人的使用情况差别很大，我们很难在此列举所有类型的软件，而只能罗列一些大家都需要的类型。

如果你在这里没有找到自己需要的软件，请按照本文开头的几个原则，自己搜索寻找。

比如，你想寻找开源的视频编辑软件，那就搜索“开源软件+视频编辑”，或者 "open source+video editor"，很容易就能找到一些软件。
