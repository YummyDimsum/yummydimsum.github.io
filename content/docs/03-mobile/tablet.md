# 平板电脑

目前主流的平板电脑分为两大类：

- 由苹果公司生产、运行 iPadOS 系统的 iPad; 

- 由其他许多公司生产、运行 Android 系统的各类平板。

虽然我们叫它“平板电脑”，但它从各方面来看都更像是一台大屏幕的手机，而不像传统的电脑。

因此，购买使用平板电脑的注意事项和购买使用智能手机的注意事项差不多。也就是：

- iPad 的优势与局限，请参考 iPhone 的优势与局限。

- Android 平板的优势与局限，请参考 Android 手机的优势与局限。
