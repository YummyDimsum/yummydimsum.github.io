# 手机设备及操作系统

智能手机的硬件日益强大，移动互联网也日益发达，人们越来越依赖智能手机上网和办公。但是，与电脑相比，智能手机更容易泄露隐私，带来安全风险。

虽然我们建议高风险人士尽量减少使用智能手机处理敏感事务，但又不可能完全不用智能手机。

在这一章，我们重点说明在中国选择和使用智能手机的注意事项，还会附带关于平板电脑的内容。

目前主流的智能手机分为两大类：

- 由苹果公司生产、运行 iOS 系统的 iPhone; 

- 由其他许多公司生产、运行 Android 系统的 Android 手机，中文又称“安卓手机”。

其他诸如 Windows Phone 之类的使用人数很少，本文暂不讨论。
